# 现实逻辑判断

## 1. 执行流程

### 1.1 启动

读到此步骤即执行。以当前全部已知信息（推理链、结论、关联网络等）为原料，引入现实世界的客观规律、常识、时间观念与发展逻辑，对推理做现实逻辑校验；前序步骤未执行时以当前对话上下文中的全部显性信息为原料。

### 1.2 建立时间标尺

提取所有信息中的时间要素（起点、长度、终点、节奏），建立统一时间坐标系后做一致性检查：时间冲突（两段信息互斥）、时间缺口（推理需要但信息缺失）、时间模糊（"很快""不久"须尽可能明确化）。

### 1.3 逐条现实校验

对每条推理/结论按以下顺序校验：

- **常识检验**：结论在常识下是否成立？不成立则检查是否有特殊条件可调和，无法判断则标"超出常识范围"。突破常识必须走正当化流程：识别被突破的常识→提供具体支撑证据→评估风险敞口→标注反常识状态→持续监控，高风险判断须在结论中显式警示。
- **时间边界**：时间标尺与现实发展节奏是否匹配？节奏异常标注评估，时间冲突标记矛盾。
- **条件依赖**：推理依赖的前提在现实中是否合理？条件脆弱标"脆弱推理"，条件已不成立则推翻。
- **动态发展**：是否考虑了动态变量（生存条件、救援行动、自身移动、条件变化、第三方介入）？静态假设过多标"静态风险"，未考虑变化标"缺乏动态维度"。
- **概率校准**：评估现实发生概率（可能/大概率/几乎不可能），参考客观数据，主动压低乐观偏差。

### 1.4 二次判断

将多条信息叠加，产生单一来源无法得出的新判断（如"凶险被困 + 三个月跨度"叠加得出生存可能性极低）；终结无法调和的矛盾：冲突按 L1 表面/L2 程度/L3 方向/L4 前提分级，L3 以上按优先级规则（类型→时效→具体性→一致性）裁决，无法裁决则悬置并输出条件分支；卦象与常识冲突时，双方确认无误则卦象优先（其"吉"可能需重新解读），保留张力。重估所有结论置信度，整体直觉"不对劲"时追查原因。

### 1.5 修正与输出

按校验结果执行修正：推翻（与现实严重冲突且无特殊条件调和）、降级（弱冲突，降低置信度）、调整（方向对但幅度/时间/条件有偏差）、补充（缺现实支撑条件）、悬置（待验证，不纳入结论）。输出完整保留之前全部信息，叠加校验记录与修正结论；每条判断标注所依据的客观规律，不确定的标注置信度与风险。

### 1.6 迭代与完成

硬性触发（关键信息缺口、时间断裂、L3 以上未解决冲突、反常识支撑证据被削弱）必须返回上游补全；软性触发（次要缺口、L2 冲突、认知边界）可带标记继续。迭代最多 3 次，每次须有新信息输入；超过上限则输出当前最佳判断并标注"基于不完全信息"。完成后标记"现实逻辑判断 已完成"，进入下一步骤。
