# 注意力发散

## 1. 执行流程

### 1.1 启动

读到此步骤即执行。以课式总表为原料，以子问题体系为锚点，同时回归课式本身发散拓展。只扫描课式已有的显性信息，只做一步推导，不依赖外部信息。

### 1.2 知识库查询

对课式总表中实际出现的符号查询知识库中对应的象义等知识，仅查询课式中已有且知识库已收录的符号，不查询未出现的符号。以查询结果为基准，但不刻板、不教条，基于此灵活运用、灵活推理，鼓励做多层延伸与推导，发挥越深入越好。

### 1.3 符号级扫描

逐符号遍历课式全部显性信息（日干日支→四课→三传→天地盘→年命→神煞→课格与毕法），每个符号输出：看到了什么、意味着什么、注意到了什么、初步判断。

### 1.4 组合级扫描

对同宫叠加、课上组合、传中组合、课传交叉、对冲、三合六合、刑穿破害、年命交差、神煞集群等组合逐类配对分析，每个组合必须给出方向性初步判断（吉/凶/中性/待定）；多神煞指向矛盾时如实标注，不强行统一。

### 1.5 链条级扫描

将多个符号与组合串联为逻辑链条（三传趋势、四课关系、干支关系、毕法体现、神煞分布、空亡入墓、多符号矛盾、重复信号、信息缺口），以"我注意到……"等内部通报式表达给出主动发现，而非转述已有信息；链条断裂处标记缺口，不强推。

### 1.6 强制收敛

扫描全部完成后执行：标记待验证项；提取关键信号。收敛只打开方向，不锁死结论，深入判断留给后续步骤。

### 1.7 输出与完成

按符号级→组合级→链条级→收敛顺序输出；每个发现须能追溯课式依据；矛盾发现优先于一致发现。完成后标记"注意力发散 已完成"，进入下一步骤。
