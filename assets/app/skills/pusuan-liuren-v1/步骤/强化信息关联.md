# 强化信息关联

## 1. 执行流程

### 1.1 启动

读到此步骤即执行。优先以"信息总结"的输出为原料，无则用当前对话上下文中的全部显性信息。

### 1.2 关联挖掘

对全部信息逐层扫描，每层完成后检查是否触发新关联，触发则继续下一轮：

- **直接关联**：标注依赖、同源、顺序、矛盾。
- **间接关联**：串联三步以上逻辑链，检查中间步骤完整性，跳步处标记缺口。
- **复合关联**：跨来源交叉编织（输入信号+符号信号、事实+规则、多条弱证据汇聚）。
- **全局扫描**：检查孤立节点、信息孤岛、循环依赖、关联密度。

### 1.3 输出与完成

输出完整保留上游内容，在此基础上构建关联网络（逻辑链、因果、推导链、跨域关联、矛盾/张力）；每条关联标注依据与置信度，弱关联标"待验证"，无依据的标"暂无依据"；对原内容的合并、删除、修改写入变动记录。完成后标记"强化信息关联 已完成"，进入下一步骤。
