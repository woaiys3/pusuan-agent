# 技能目录

本目录存放普算的**技能**。**每个技能 = 一个文件夹，技能正文固定命名为 `SKILL.md`**：

```
skills/
├── README.md                  ← 本说明文档，不参与扫描
├── 示例技能/
│   └── SKILL.md               ← 技能正文
└── 六爻/
    ├── SKILL.md               ← 技能主流程
    └── 排盘表.md              ← 附件（可选），由 SKILL.md 里的流程用 Read 工具按需读取
```

## SKILL.md 格式

顶部用 yaml frontmatter 声明元信息：

```markdown
---
name: 技能名称
description: |
  技能的一句话描述 + 适用场景。描述越清楚，AI 越容易在正确时机自动调用。
---

# 技能内容

从正文开始写技能的完整流程、规则、步骤…… AI 调用该技能时会读到全文。
```

## 规则

- **技能必须是一个文件夹**，正文文件名须为 `SKILL.md`（大小写不敏感），否则不会被识别
- `name`：技能名称，AI 调用 `skill_select` 时用它指定。建议与文件夹名一致；缺失时默认用文件夹名
- `description`：**必须有**，否则技能不会被识别。写在描述里"什么场景下用"是触发关键
- **多文件技能**：附件放同一个文件夹内，在 `SKILL.md` 里写清楚路径，AI 会按需用 Read 工具读取
- 改动 `SKILL.md` 后**下一条消息立即生效**，无需重启
